# Backlog チケット起票テンプレート (aidevflow 推奨)

> **使い方**:
> Backlog で新規課題を起票する際、以下の Markdown テンプレートをコピー＆ペーストして要件を記入してください。
> 機能要件（A）だけでなく、非機能要件・エッジケース・既存制約（B）を明記することで、AI エージェントの手戻りや暴走を未然に防ぐことができます。

- **新機能実装** (設計 ➔ 実装 ➔ PR作成)
